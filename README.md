# Conway's Game of Life (Игра «Жизнь»)

Простая реализация знаменитого клеточного автомата Джона Конвея «Игра „Жизнь“» на языке Java.

## Требования
* **Java:** Версия 26 или выше.

## Как запустить проект

Вы можете запустить эту программу двумя способами:

### Способ 1: Открыть проект в IntelliJ IDEA (Рекомендуемый)
1. Скопируйте URL-ссылку этого репозитория.
2. Откройте **IntelliJ IDEA** и на главном экране нажмите кнопку **Get from VCS** (или выберите в меню `Git -> Clone...`).
3. Вставьте ссылку в поле **URL** и нажмите **Clone**.
4. Дождитесь индексации проекта, найдите файл `src/GameOfLife.java` и нажмите зеленую стрелку **Run** (Запустить) рядом с методом `main`.

### Способ 2: Запуск в любой другой среде разработки или терминале
Если вы хотите запустить код без клонирования всего репозитория:
1. Перейдите в папку `src/` в этом репозитории и откройте файл `GameOfLife.java`.
2. Скопируйте весь текст кода.
3. Вставьте его в любой удобный онлайн-компилятор Java или создайте файл `GameOfLife.java` в предпочитаемой IDE (Eclipse, NetBeans, VS Code).
4. **Запуск через терминал:**
   ```bash
   javac src/GameOfLife.java
   java src/GameOfLife
   ```
